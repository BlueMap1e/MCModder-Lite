## 二、摘要（简介 / 列表页，约 100 字）

MCModder-Lite 是一款开源的 MC 百科编审辅助脚本，基于 Mcmodder 2.4.1 精简而来。它只保留改正文、查资料、修表格、看审核列表这些高频功能，去掉云端服务与娱乐模块，并修复了正文以表格结尾、长正文统计报错、`?mrid` 清空正文等问题。免费、无广告、数据全部保存在本地。

## 三、正文（Markdown）

### 这是什么

MCModder-Lite 是一款运行在 MC 百科（mcmod.cn）上的用户脚本，装好篡改猴后打开百科页面即可使用。它给百科编辑与审核流程加了一层更顺手的界面：夜间模式、编辑器增强、自动链接、表格修复、待审列表重排等等。

它源自 [Mcmodder](https://github.com/Charcoal-Black/Mcmodder) 2.4.1，但不是简单地「复制一份」：我按自己每天编资料、审条目的实际用法做了取舍，删掉了用不上的模块，也修掉了几个一直在影响正文编辑的问题。项目以 AGPL-3.0 开源，源码在 [GitHub](https://github.com/BlueMap1e/Mcmodder-Lite)。

### 它想解决什么问题

编辑百科时真正高频的动作其实很固定：改正文、贴资料链接、修表格、看待审列表，以及晚上不刺眼地做完这些事。Mcmodder-Lite 围绕这些场景做减法：

- **体积更小**：用户脚本 2.3 MB（上游 2.9 MB），外部依赖从 4 个减到 1 个，不再加载 Supabase、three.js 等库。
- **设置都能用**：清掉了 16 个「勾了没反应」的开关，设置界面里能看到的都是真的生效的。
- **不连第三方云**：没有账号体系、没有云端表态、没有数据上报；只有「日志智能管理」在编辑日志页按需请求 CurseForge / Modrinth 的公开接口。
- **修掉编辑器的老问题**：正文以表格结尾没法换行、长正文时字节统计反复报错、`?mrid` 日志页自动转换清空正文等，见下方清单。

### 和 Mcmodder 是什么关系

Lite 是 Mcmodder 的硬分叉，与上游团队没有隶属关系，也不会合并上游分支；上游的修复会按需移植过来。上游版权归 Charcoal-Black 及其贡献者，本项目同样以 AGPL-3.0 发布，并保留完整归属。

怎么选：

| 你的需求                                       | 建议          |
| ---------------------------------------------- | ------------- |
| 只想改资料、审条目，越轻越好                   | MCModder-Lite |
| 需要自定义表态、GIF 编辑器、结构浏览器、成就等 | 上游 Mcmodder |
| 不希望脚本连接任何第三方云服务                 | MCModder-Lite |
| 想随时用上最新功能                             | 上游 Mcmodder |

两者功能重叠较多，**不要同时安装**：它们会修改同一批页面，容易互相干扰。

### 功能亮点

**阅读与外观**

- 双色主题（内置「百科经典」绿 / 蓝预设）、自定义日间 / 夜间背景、字体、阴影、圆角与透明度。
- 夜间模式覆盖主站、社群、UEditor 弹窗与评分雷达图，模组封面可调暗。
- 资料页：正文表格自动折叠并左对齐、综合资料紧凑化、合成表 GUI 折叠、物品链接悬停预览。
- 短评：用户黑名单、空白行折叠、超长短评展开警告、楼中楼链接跳转、按楼层跨页跳转。
- 模组页：基本信息排版恢复、矿物词典 / 物品标签页重排、贡献榜重排。
- 广告位置优化（只挪位置，不隐藏、不屏蔽）。

**编辑与校对**

- 编辑器宽高自适应，实时显示有效正文字节数与变动量。
- Markdown 编辑器：正文一键 Markdown ↔ HTML，标题自动转换成百科兼容的 `[h1=xxx]`；源代码编辑器支持格式化与缩进风格。
- 自动链接面板：同名资料高亮、同模组（含前置 / 拓展）资料置顶、`Alt + 数字` 快速选择；可直接插入矿物词典 / 物品标签链接（搜索词加 `#`）。
- 自定义模版一键插入；图标任意尺寸上传并自动生成 32 / 128 px（BUFF 为 36 / 144）。
- 校对提示：链接冲突与旧 Fandom Wiki 链接高亮、未本地化的图片资源高亮。
- 表格墙修复：正文以表格结尾时自动补尾随行，空单元格可用方向键逃逸，清洗 nowrap 污染，并保留光标位置。
- 日志智能管理：自动比对 CurseForge / Modrinth 的文件列表与百科已收录版本，缺失版本高亮并给出新增入口。

**审核与后台**

- 待审列表紧凑化、按时间段自动展开、一键催审、按间隔自动刷新。
- 审核页左右分屏；样式管理实时预览。
- 按资料类型做提交前规则检查（链接前缀与冗余参数、必备项目 ID、空合成表等）。
- 快速通过 / 退回 / 需要检查，附言框自动聚焦。

**通用**

- 每日首次访问自动签到。
- 个人主页用户切换面板，可临时登出或切换账号。
- 设置中心按「外观 / 个人中心 / 编辑器 / 社群 / 其他」分组，多标签页同步。
- 数据只存本地：设置走篡改猴存储，较大的 JSON 可选 IndexedDB。

### 安装

1. 先给浏览器装[篡改猴](https://www.tampermonkey.net/)（Tampermonkey）。
2. 打开[一键安装地址](https://github.com/BlueMap1e/Mcmodder-Lite/releases/latest/download/mcmodder-lite.user.js)，在安装页点「安装」。
3. 打开任意百科页面即可生效。设置入口：篡改猴图标 →「打开设置」，或个人中心 →「设置」。

主测环境是 Firefox / Zen，Chrome / Edge 同源可用。脚本不内置自动更新，发新版后重新打开安装地址覆盖安装即可，设置与数据会保留。

### 常见问题

**Q：和原版 Mcmodder 能一起装吗？**
不建议。两者都改同一批页面，容易重复注入、互相干扰，请二选一。

**Q：会拖慢页面吗？**
大部分功能按页面按需执行，空闲时不做全文序列化；体积也比上游小一截。

**Q：会不会影响账号安全？**
脚本不读取、不发送你的账号密码，所有请求只发往 mcmod.cn（日志智能管理额外访问 CurseForge / Modrinth 的公开接口）。脚本不做绕过审核、伪造编辑量之类的事；自动签到等自动化操作与手动点击等价，是否使用请自行按站规判断。

**Q：数据存在哪？卸载会丢吗？**
存在篡改猴的本地存储（和可选的 IndexedDB）里，不会上传。卸载脚本或清理扩展数据会丢失设置。

**Q：百科改版后失效怎么办？**
脚本依赖页面结构，改版后可能短暂失效。到 GitHub Issues 反馈即可，维护模式下的 bug 修复会优先处理。
