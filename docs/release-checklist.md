# 发布前检查清单

> 每次发版前照此过一遍。自动检查全绿 + 手工安全回归通过，再打 `[release]`。
> 安全问题的共同点：正常输入永远不触发，必须专门用「恶意输入」验证。

## 0. 自动检查

```bash
npm run verify                    # eslint + 配置 lint + 格式
npm run build                     # 类型检查 + 构建
node scripts/smoke-public.mjs     # 公共页 7 项（无登录）
node scripts/security-smoke.mjs   # 安全回归 4 项（贡献榜，无登录）
```

## 1. 手工安全回归（需要登录态）

| 页面 / 功能                             | 造数据                                                    | 预期                                 |
| --------------------------------------- | --------------------------------------------------------- | ------------------------------------ |
| 后台待审 · 相关链接                     | 把某条链接文本改成 `<img src=x onerror="window.__xss=1">` | 以纯文本显示，不生成标签、不弹窗     |
| 后台待审 · 资料类型                     | 同上                                                      | 同上                                 |
| 待审列表 · 附言（开启「紧凑待审列表」） | 附言写 `<img src=x onerror=...> https://example.com`      | 标签以文本显示，URL 仍可点击         |
| 贡献榜                                  | 昵称含 `<img src=x onerror=...>`（可临时改 DOM）          | 纯文本显示，`javascript:` 链接被替换 |
| 短评楼中楼（开启 `replyLink`）          | 评论写 `https://x/" onmouseover="window.__xss=1`          | 不产生事件属性，链接可点             |
| 日志智能管理（`?cfid=&fileid=`）        | 用受控 CF 文件日志，正文含 `<img onerror>` / `onclick`    | 清洗后无事件属性，排版保留           |
| 资料页 · 运作方式 / 运行环境            | 正常模组页                                                | 图标、名称、标签与改动前一致         |

> 检查时在控制台输入 `window.__xss`，确认始终为 `undefined` / `0`。

## 2. 功能回归（本次改动涉及）

- [ ] 贡献榜：名次、百分比、总贡献文案、头像悬浮效果
- [ ] 资料页：运作方式图标与名称、运行环境标签、支持平台
- [ ] 日志智能管理：表格列显示、双击编辑、撤销/重做
- [ ] 断网或改 hosts 模拟请求失败：确认出现一次 toast，按钮/加载态恢复，不再永久转圈
- [ ] 短评：楼中楼链接、楼层跳转、夜间模式无异常

## 3. 发版

- [ ] `package.json` 与 `vite.config.ts` 版本号一致
- [ ] `CHANGELOG.md` 有对应 `## [x.y.z]` 小节（release notes 来源）
- [ ] 先发 **pre-release**（`releases/latest` 会忽略它），给 2–3 人安装灰度
- [ ] 灰度确认自动更新提示、夜间三态、审核页正常后，转为正式 release

## 4. 回滚

- 坏版本：在 GitHub 上把该 release 改回 **pre-release**，`latest` 会回落到上一版；安装地址不会 404。
- 已升级用户不会被自动降级：立即发一个更高版本的 hotfix。
- 发 hotfix 前仍需走本清单的 0–2 节。
