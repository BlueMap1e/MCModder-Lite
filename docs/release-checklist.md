# 发版前怎么检查（照着做就行）

你只需要做两件事：

1. **复制一条命令，等 2 分钟，看最后一行。**
2. **点三处页面，看有没有变丑 / 变坏。**

安全攻击测试已经自动化了。**不需要你改数据、写 payload，也不需要懂 XSS。**

---

## 第 1 件：一条命令

在项目文件夹打开终端，复制这一行、回车：

```bash
npm run check
```

第一次跑会启动浏览器，慢一点是正常的。

屏幕上会依次出现四段：

- 第 1/4 步：检查代码规范
- 第 2/4 步：把源码打包成脚本
- 第 3/4 步：自动打开百科页面测试（会自己开浏览器，不用管它）
- 第 4/4 步：自动模拟坏输入测试

最后只会是两种结果之一。

### 结果 A：全部通过

```
结果：全部通过，可以发版。
```

→ 继续做第 2 件。

### 结果 B：没有通过

```
结果：没有通过（卡在「第 x/4 步：...」）。
```

→ **不要发版**。把终端最后 20 行复制发给我就行，不用自己排查。

> 如果某一步显示 `SKIPPED`：不是坏事，是百科弹了「安全验证」把自动测试拦住了。等几分钟再跑一次，或者换个网络。

---

## 第 2 件：点三处（约 2 分钟）

自动测试看不出「长得好不好看」，所以下面三处用眼睛看。
**不需要懂安全，只看它和以前是不是一样。**

### 1. 审核页的「相关链接」

- 打开后台 → 待审列表 → 随便点开一个待审项。
- 找到「相关链接」那一行。
- **正常**：方括号后面的链接是蓝色、能点，文字没变成乱码或空白。
- **不正常**：截图发我。

### 2. 贡献榜

- 打开 <https://www.mcmod.cn/rank.html>
- 看名次、头像、百分比，以及最下面「全体百科用户……」那一行。
- **正常**：和以前一样，头像能显示、数字没乱。
- **不正常**：截图发我。

### 3. 任意模组页 + 日志页

- 打开任意模组页，看「运作方式」的图标和「运行环境」的小标签。
  **正常**：图标在、文字在、没有错位。
- 再打开一个编辑日志页，点「补全日志」。
  **正常**：日志内容会出现在编辑器里。
- **不正常**：截图发我。

> 这三处只要「看起来和以前一样」，就说明这次安全修改没有弄坏功能。

---

## 第 3 件：发版（第 1、2 件都过了再做）

1. 把 `package.json` 和 `vite.config.ts` 里的版本号改成同一个新版本。
2. 在 `CHANGELOG.md` 最上面加一节 `## [新版本号] - 日期`，写人话即可。
3. 提交信息里带 `[release]`，推送。
4. CI 会自动建好**正式** release（发布脚本直接 `gh release create`，没有草稿或预发布标记），
   不需要你在发布页填任何东西。
5. 帖子里换 zip 附件：跑 `npm run pack`，产物在 `dist/release/`，把里面的 zip 传到宣发帖。
   （GreasyFork 渠道已于 2026-11-10 废止——未压缩包超出其 2,097,152 字符上限，详见 HANDOFF。）
6. 想先小范围验证就手动降级：打开该 release → 右上角编辑（铅笔图标）→ 勾选
   「Set as a pre-release」→ 保存；装 1–2 台机器确认没问题后，再取消勾选改回正式版。

---

## 出了问题怎么办

- 不要改代码，不要回滚。
- 把 `npm run check` 最后 20 行 + 截图发给我。
- 如果已经发出去了：在 GitHub 把该 release 改回 pre-release，安装地址会自动回到上一版；已经安装的人需要等下一个修复版。

## 名词小抄（看不懂可以跳过）

| 词          | 人话                                                    |
| ----------- | ------------------------------------------------------- |
| XSS         | 别人在页面里塞一段代码，让浏览器执行                    |
| payload     | 我测试用的一段「坏代码」，已经写进自动测试，你不用管    |
| 回归        | 改完确认原来的功能没被弄坏                              |
| pre-release | GitHub 的「预发布」，普通人搜不到，只有拿到链接的人能装 |
